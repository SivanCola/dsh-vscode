# Changelog

## 0.0.1

- First public release of the DeepSeek Harness sidebar for VS Code.
- Resume workspace conversations, change model and reasoning settings, and handle Harness tool approvals.
- Attach files, paste images, and include editor selections or chat quotes in your message.
- Use slash commands for conversation and sidebar actions. The interface supports English and Simplified Chinese.

## Local development builds

### 0.9.1

- Paste copied images or screenshots directly into the message input to attach them.

## 0.9.0

- Attach multiple files from the composer, preview or remove them, and send text, supported images or local file links with the conversation.

## 0.8.0

- Type `/` in the chat input to choose local commands and change the current session's model or reasoning effort.

## 0.7.0

- Add selected chat excerpts or editor code to the current conversation, with a second action to focus the composer for a follow-up.

## 0.6.0

- Press Enter to send and Shift+Enter to insert a new line. Harness Settings shows both shortcuts and lets you turn off Enter-to-send.

## 0.5.0

- Switch between English, Simplified Chinese and the editor language inside Harness Settings. Language changes preserve the active conversation and draft.

## 0.4.0

- The settings gear opens a page inside the sidebar with provider and model selectors, runtime controls and editor tools. Return to chat to continue the same draft.

## 0.3.0

- Choose a provider and model for new conversations in Harness Settings, or follow the ACP profile default. Existing conversations retain their selected model.

## 0.2.0

- Added a native Harness Settings menu, direct profile access after authentication failures, and customizable send and stop shortcuts.

## 0.1.0

- Added ACP v1 chat, editor selection attachments, tool approval, model settings, cancellation, and conversation recovery.
